# Blockchain-Based Class Attendance System

A blockchain-based attendance management system built to record and manage student attendance securely using the Monad Testnet. The application allows teachers to create classes, add students, and record attendance through MetaMask wallet integration.

## Features

* **Create Classes:** Teachers can create and manage classes.
* **Add Students:** Add students using their names and wallet addresses.
* **Blockchain Attendance:** Record and verify attendance transactions on the blockchain.
* **MetaMask Integration:** Connect wallets and interact with the Monad Testnet.
* **Attendance Tracking:** View student attendance records and percentages.
* **Excel Export:** Download attendance records for further use.
* **Web Deployment:** Access the application through Vercel.

## Technologies Used

* Blockchain: Monad Testnet
* Wallet: MetaMask
* Smart Contracts: Solidity
* Deployment: Vercel

## Live Demo

[Open the Attendance System](https://attendance-app-topaz-one.vercel.app)

## How to Use

1. Open the application using the live demo link.
2. Connect your MetaMask wallet and switch to the Monad Testnet.
3. Create a class.
4. Add students using their names and wallet addresses.
5. Start a lecture and allow students to mark their attendance.
6. End the lecture and view attendance records.
7. Download the attendance report for Excel.

## Network Details

* **Network:** Monad Testnet
* **Chain ID:** 10143
* **Currency:** MON
* **RPC URL:** https://testnet-rpc.monad.xyz

## Purpose

The purpose of this project is to demonstrate how blockchain technology can be used to create a transparent and verifiable attendance management system, reducing reliance on traditional manual attendance methods.
